# Źródła makiet

Pliki `.dc.html` to plansze z narzędzia Claude Design (5 plansz, każda z telefonem w motywie
jasnym i ciemnym, 390x844). Nie otwierają się samodzielnie w przeglądarce, bo wymagają
środowiska uruchomieniowego narzędzia (`support.js`). Służą jako dokładne źródło: kolory,
rozmiary, odstępy i teksty można z nich odczytać wprost. Układ plansz: `canvas.json`.

Plansze: Main (mapa), Osoba (arkusz osoby), Czat, Krag (krąg i prywatność), Zasady (tokeny).
Tokeny wartości są też w `docs/DESIGN.md`. Postacie (Marta, Kuba, Hela) i treści są wymyślone.
Czcionki w makietach ładują się z Google Fonts; w aplikacji mają być lokalne (zadanie F2-7).
Makiet nie sprawdzano wizualnie (kontrast, przepełnienia tekstu).
